Создай веб-игру «Арфа Браги» (Bragi's Harp) на Python/Flask — мини-игру 
в скандинавском стиле для сайта крафтовой пивоварни. Игра должна быть 
встроена в сайт магазина как геймификация: игрок играет, зарабатывает 
«медовуху» и обменивает её на промокоды/скидки на крафтовое пиво.

═══════════════════════════════════════════
1. КОНЦЕПЦИЯ ИГРЫ (то, что сейчас в тренде)
═══════════════════════════════════════════
Жанр: ритм-кликер / «сочини сагу» — простая, залипательная, мобильная.
- Игрок — скальд, который играет на волшебной арфе бога Браги.
- Механика: по экрану летят руны (ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ), нужно тапать по ним 
  в такт. Серия попаданий (combo) увеличивает множитель очков.
- Валюта: «медовуха» 🍯 — начисляется за очки.
- Прокачка (магазин внутри игры):
  • Струны арфы (+очки за попадание)
  • Рог для питья (+медовуха за сессию)
  • Благословение Одина (замедление времени на 5 сек)
  • Пиво с пивоварни (+20% ко всему на 3 игры — связка с реальным товаром)
- Ежедневный бонус (streak): заходишь каждый день — награда растёт.
- Достижения: «Убийца ётунов», «Любимец Браги», «100 комбо» и т.д.
- Таблица лидеров (топ-10 скальдов за неделю).
- Награда: при накоплении N медовухи игрок получает ПРОМОКОД 
  (например, BRAGI10 = скидка 10% в магазине) — код генерируется 
  на сервере, одноразовый, сохраняется в БД.

═══════════════════════════════════════════
2. ЛОГОТИПЫ И БРЕНДИНГ (ВАЖНО!)
═══════════════════════════════════════════
В папке /static/logo/ лежат мои логотипы. Используй их:
- Найди их автоматически (glob по *.png/*.svg/*.webp) или возьми 
  logo.* как основной.
- Логотип: в шапке сайта, на заставке игры (splash screen), favicon, 
  на экране «Победа/Промокод», в карточке шаринга.
- Стилистику игры подгони под цвета логотипа (извлеки доминирующие 
  цвета или используй CSS-переменные, которые я смогу поменять).
- НЕ перерисовывай логотип, используй файлы как есть.

═══════════════════════════════════════════
3. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
═══════════════════════════════════════════
- Python 3.11+, Flask, SQLite (через sqlite3 или SQLAlchemy).
- Фронтенд: чистый HTML/CSS/JS (Canvas или DOM), БЕЗ сборщиков и 
  тяжёлых фреймворков — чтобы просто запустить flask run.
- Состояние игрока: localStorage + синхронизация с сервером (API).
- Простая античит-защита: очки проверяются на сервере (лимит за сессию), 
  промокоды — только серверная генерация.
- Полностью адаптивно: mobile-first, играется одним пальцем.

Структура проекта:
brewery-game/
├── app.py                 # основное приложение
├── config.py
├── models.py              # игроки, очки, промокоды, достижения
├── requirements.txt
├── README.md              # инструкция запуска и настройки
├── templates/
│   ├── base.html          # общий layout с логотипом
│   ├── index.html         # главная: витрина + кнопка «Играть»
│   ├── game.html          # экран игры
│   ├── leaderboard.html   # таблица лидеров
│   └── rewards.html       # обмен медовухи на промокоды
└── static/
    ├── logo/              # ← МОИ ЛОГОТИПЫ (не трогать)
    ├── css/style.css
    ├── js/game.js         # игровая логика на Canvas
    ├── audio/             # звуки струн арфы (сгенерируй через WebAudio)
    └── img/               # руны, арфа, драккары, рога (SVG/CSS-арт)

Страницы и API:
- GET  /                → главная с витриной пивоварни и входом в игру
- GET  /game            → игра
- GET  /leaderboard     → топ игроков
- GET  /rewards         → магазин промокодов
- POST /api/score       → сохранение результата (name, score, combo)
- POST /api/promo       → обмен медовухи на промокод
- GET  /api/me          → профиль игрока (очки, streak, достижения)
- GET  /admin/promos    → простая админка: список выданных промокодов 
                          (доступ по паролю из config)

4. ДИЗАЙН (тренды 2025-2026)
═══════════════════════════════════════════
- Тёмная тема: угольно-чёрный + золото + медно-пивные акценты.
- Эстетика: «крафтовая этикетка» — рунический орнамент, текстура 
  дерева и пергамента, леттеринг как на банках крафта.
- Шрифты: заголовки — с руническим/готическим характером (Google Fonts: 
  например Cinzel, Uncial Antiqua), текст — читаемый гротеск.
- Анимации: плавные (CSS transitions), частицы при комбо, лёгкое 
  свечение рун, экран тряски при промахе — но без перегруза.
- Кнопка «Поделиться результатом» — генерирует красивую карточку 
  с логотипом пивоварни, очками и руной (Canvas → PNG).
- Тёмный UI должен хорошо смотреться рядом с фотографиями пива.

═══════════════════════════════════════════
5. ИНТЕГРАЦИЯ С МАГАЗИНОМ
═══════════════════════════════════════════
- На главной — блок-витрина: 4-6 карточек крафтового пива (название, 
  стиль, ABV/IBU, цена, фото-заглушка) + кнопка «В магазин» 
  (ссылку я вставлю сам в config.py: SHOP_URL).
- В игре пасхалки: бонусные руны-«бочки» с логотипом дают x2 очки.
- После промокода — CTA «Активировать в магазине» со ссылкой на SHOP_URL.
