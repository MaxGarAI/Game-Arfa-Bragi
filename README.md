# 🎻 «АРФА БРАГИ» (Bragi's Harp)
### Скандинавская веб-игра & геймификация для крафтовой пивоварни

Веб-приложение на **Python / Flask** в трендовом скандинавском крафтовом стиле (угольно-чёрный фон, золото, медно-пивные акценты, руническая эстетика). Игра встроена в сайт пивоварни как маркетинговая воронка: посетитель играет за скальда, выбивает руны на арфе бога Браги, зарабатывает игровую валюту — «медовуху» 🍯 — и обменивает её на реальные одноразовые промокоды на крафтовое пиво и фирменных раков.

---

## ⚡ Особенности и возможности

1. **Ритм-кликер на Canvas (HTML5)**:
   - 4 магические струны арфы Браги.
   - Падающие руны Старшего Футарка (`ᚠ`, `ᚢ`, `ᚦ`, `ᚨ`, `ᚱ`, `ᚲ`...) и пасхалки — золотые бочонки крафта с множителем `x2`.
   - Система комбо с множителями очков до `10x` («Ярость Вальхаллы»).
   - Акустический синтез струн арфы через **Web Audio API** (без внешних MP3-файлов, работает автономно и мгновенно).
   - Активный навык: **«Благословение Одина»** (замедление времени на 5 секунд в стиле bullet-time).
   - Mobile-first: играется одним пальцем на любом смартфоне + управление клавишами `D, F, J, K` или `1, 2, 3, 4` на ПК.

2. **Брендинг и логотипы**:
   - Автоматический поиск логотипов в каталоге `/static/logo/` (`logo.png`, `emblem_gold.png`, `favicon.png`).
   - Использование фирменных шрифтов *Cinzel Decorative*, *Unbounded* и *Montserrat*.
   - Генератор карточки результата: рендеринг красивой квадратной карточки (1080x1080) с логотипом пивоварни, счётом и рунами для публикации в соцсетях или мессенджерах через Canvas → PNG / Web Share API.

3. **Экономика и прокачка (Лавка Скальда)**:
   - Струны арфы: `+20%` очков за каждое попадание.
   - Рог для питья: `+25%` медовухи за игровую сессию.
   - Свитки замедления времени Одина.
   - Свежий крафт с пивоварни: бафф `+20%` ко всем показателям на 3 игры.
   - Ежедневный бонус за вход (Streak): награда растёт каждый день подряд (от 30 до 300 🍯).

4. **Интеграция с магазином и промокоды**:
   - Обмен медовухи на уникальные серверные промокоды (`BRAGI5`, `BRAGI10`, `SKALD15`, `ODIN20`, `RAKI-GIFT`).
   - Кнопка «Активировать в магазине» с переходом по `SHOP_URL`.
   - Витрина крафтового пива («Солнце домов», «Берег мечей», «Волшебный трут», «Молот Тора») со спецификациями ABV/IBU/плотность.
   - Защита от накруток (античит): лимиты очков за секунду, проверка длительности сессии, строгая серверная генерация кодов.

5. **Чертог Ярла (Админ-панель)**:
   - Доступ по паролю из конфигурации (`/admin/promos`).
   - Просмотр всех выданных кодов, поиск по имени и коду, фильтрация по статусу.
   - Погашение промокодов на кассе в 1 клик.
   - Экспорт базы промокодов в CSV.

## 🚀 Быстрый старт локально

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.11+:
```bash
pip install -r requirements.txt
```

### 2. Заполнение базы данных тестовыми игроками (опционально)
Скрипт создаст 15 легендарных скандинавских скальдов для таблицы лидеров:
```bash
python seed.py
```

### 3. Запуск веб-сервера
```bash
python app.py
```
или через Flask CLI:
```bash
flask run --port=5000
```

Откройте в браузере:
- **Главная страница**: [http://localhost:5000/](http://localhost:5000/)
- **Игра «Арфа Браги»**: [http://localhost:5000/game](http://localhost:5000/game)
- **Обмен наград**: [http://localhost:5000/rewards](http://localhost:5000/rewards)
- **Таблица лидеров**: [http://localhost:5000/leaderboard](http://localhost:5000/leaderboard)
- **Админка промокодов**: [http://localhost:5000/admin/promos](http://localhost:5000/admin/promos)

## ⚙️ Настройка конфигурации (`config.py` или ENV)

Все ключевые параметры вынесены в `config.py` и могут переопределяться через переменные окружения:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `SHOP_URL` | `https://arfabragi.ru` | Ссылка на ваш интернет-магазин пива |
| `ADMIN_PASSWORD` | `skald_secret_2026` | Пароль для доступа в `/admin/promos` |
| `SECRET_KEY` | `bragi-harp-viking...` | Секретный ключ сессий Flask |
| `POINTS_PER_MEAD` | `100` | Курс начисления: сколько очков дают 1 🍯 |

### Изменение стоимости и типов промокодов:
В файле `config.py` в словаре `PROMO_TIERS`:
```python
'BRAGI10': {
    'id': 'BRAGI10',
    'title': 'Скидка 10% на весь чек',
    'desc': 'Хитовый промокод скальда на все сорта и напитки',
    'mead_cost': 300,            # Стоимость в медовухе
    'discount_percent': 10,       # Процент скидки
    'prefix': 'BRAGI10',         # Префикс генерируемого кода
    'badge': 'Популярный'
}
```

## 📱 Как запустить игру на телефоне через GitHub Pages (Бесплатно, без сервера)

В проекте уже сгенерирована полностью автономная веб-версия в папке `/docs`. Она работает в браузере любого смартфона: сохраняет прогресс в `localStorage`, генерирует промокоды, воспроизводит звук арфы через Web Audio API и генерирует карточки результатов.

### Инструкция по публикации за 2 минуты:

1. **Создайте репозиторий на GitHub**:
   - Перейдите на [github.com/new](https://github.com/new) и создайте новый публичный репозиторий (например, `bragi-harp`).
2. **Загрузите файлы проекта в репозиторий**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Bragi's Harp game"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/bragi-harp.git
   git push -u origin main
   ```
3. **Включите GitHub Pages**:
   - В вашем репозитории на GitHub перейдите в **Settings** (Настройки) → **Pages** (в левом меню).
   - В блоке **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: выберите `main`
     - **Folder**: выберите `/docs` *(важно! именно папку `/docs`)*
     - Нажмите **Save**.
4. **Готово!**
   Через 30–60 секунд GitHub выдаст вам публичную ссылку вида:
   `https://<ваш-логин>.github.io/bragi-harp/`
   
   Откройте эту ссылку на телефоне или отправьте друзьям: игра запустится мгновенно, без установки сторонних приложений!

> **Обновление статической версии**: если вы измените что-то в шаблонах или логике, просто выполните `python export_static.py`, закоммитьте изменения в Git и запушьте на GitHub.

## ☁️ Альтернатива: Полноценный бэкенд на Python (Render.com / Railway)

Если вам нужна общая серверная база данных игроков, централизованная таблица лидеров и админка выдачи промокодов для кассиров:
1. Зарегистрируйтесь на бесплатном сервисе [Render.com](https://render.com).
2. Нажмите **New +** → **Web Service** и подключите ваш GitHub-репозиторий.
3. Укажите параметры:
   - **Environment**: `Python`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app` (или `python app.py`)
4. Нажмите **Deploy Web Service**. Через минуту Render выдаст публичный HTTPS-адрес (например, `https://arfa-bragi.onrender.com`), который будет полноценно работать со всеми серверными API на телефоне и ПК.

---

### С помощью Gunicorn + Systemd:
1. Установите Gunicorn:
   ```bash
   pip install gunicorn
   ```
2. Запустите сервис:
   ```bash
   gunicorn -w 4 -b 0.0.0.0:5000 app:app
   ```
3. Для Nginx настройте стандартный `proxy_pass http://127.0.0.1:5000;`.
